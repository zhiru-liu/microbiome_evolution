This project provides associated computer code for the manuscript:

Liu Z, Good BH. Dynamics of bacterial recombination in the human gut microbiome. PLoS Biol. 2024 Feb 8;22(2):e3002472. doi: 10.1371/journal.pbio.3002472. PMID: 38329938; PMCID: PMC10852326. https://doi.org/10.1371/journal.pbio.3002472

More documentation to come! Please email me (zhiru at stanford.edu) in the meantime for any questions.

Unfortunately, all analysis code in this repo is python2 due to legacy code inherited from the previous project. **A python3 implementation of the CP-HMM package is now available** (see the update below); new users should start there.

## Update 2026-09-18

The close-pair HMM (CP-HMM) used in this paper has been reimplemented in python3 as a standalone, pip-installable package: https://github.com/zhiru-liu/close_pair_hmm

It includes helpers for loading the Zenodo SNV catalogs (below) and a workflow that re-runs recombination detection on the quasi-phased gut cohort and compares the results against the transfers reported in the paper. It is also the recombination-detection backend for our follow-up work on dN/dS dynamics (https://github.com/zhiru-liu/dNdS_dynamics). The python2 code in this repo is kept as the archival version used for the published figures.

## Update 2025-02-11

After a long while, I finally uploaded a compressed version of the SNV catalogs to Zenodo (https://zenodo.org/records/14853785), which will hopefully be much easier to access. These catalogs were originally generated by Garud et al. using the "quasi-phasing" approach. Some helper code for getting SNV distributions like Fig 2b can be found in this repo.
