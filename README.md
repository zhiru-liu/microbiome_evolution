This project provides associated computer code for the manuscript:

Liu Z, Good BH. Dynamics of bacterial recombination in the human gut microbiome.
PLoS Biol. 2024 Feb 8;22(2):e3002472. doi: 10.1371/journal.pbio.3002472. PMID: 38329938; PMCID: PMC10852326.
[https://doi.org/10.1371/journal.pbio.3002472](https://doi.org/10.1371/journal.pbio.3002472)

More documentation to come! Please to email me (zhiru at stanford.edu) in the mean time for any quetions.

*Unfortunately, all analysis code is python2 due to legacy code inherited from the previous project. A python3 version of the CPHMM package is coming soon.*

## Update 2025-02-11
After a long while, I finally uploaded a compressed version of the SNV catalogs to [Zenodo](https://doi.org/10.5281/zenodo.14853785), which will hopefully be much easier to access.
These catalogs were originally generated by [Garud et. al.](https://doi.org/10.1371/journal.pbio.3000102) using the "quasi-phasing" approach.
Some helper codes for getting SNV distributions like Fig2b can be found in [this repo](https://github.com/zhiru-liu/LiuGood-2024-SNVs).
